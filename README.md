# Piano Typer 🎹⌨️

Type with your piano. One key = one letter. Press all the letters of a word
**together as a chord** and the whole word appears — a local AI works out which
word you meant ("stop" vs "spot" vs "post") from what you've written so far.
Keys glow on screen to show the likely next letters, and suggested words show the
chord that types them.

Your keyboard has no MIDI port, so the laptop **listens** to it through the USB
sound card and works out which keys you pressed.

## Plug in

1. Aux cable: keyboard **PHONES/OUTPUT** → USB sound card's **mic** socket (Y-cable).
2. USB sound card → laptop.
3. Keyboard volume about **1/4 to 1/2**. Use the **Acoustic Grand Piano (000)** sound:
   in testing it gave the best chord detection (organ is fine for single letters but
   worse for big chords). Turn off rhythms/accompaniment and effects.
4. Headphones go in the sound card's headphone socket if you want to hear it
   (Windows: Sound → Recording → Microphone (USB PnP Audio Device) → Properties →
   Listen → "Listen to this device").

## Start

Double-click **`run.bat`**. It opens http://localhost:8765 in your browser.
(Ollama should be running for the AI part; the app still works without it.)

## First-time setup (1–3 minutes, in the ⚙ settings drawer)

1. **Find lowest key** → press the far-left key once. This tells the app how your
   keyboard is tuned.
2. **Calibrate all keys** (recommended) → press each glowing key once. This teaches
   the app exactly how *your* keyboard sounds, which makes chords much more
   reliable. Letters come first; you can Skip/Cancel any time and it keeps what it
   learned.

## Playing

The keys are laid out like **a laptop keyboard folded flat into one row**:

```
  far left            left-hand letters         centre (thumbs)        right-hand letters    right       top
↶ S1 ⌫w S2 S3 ⇧ | x q z d r v s f a b w t g e c | ⌫  ␣  ×2  ✓ | h o i p l k j y u n m | . ' , ? - ! ↵ | 1-9 0
                   rare ───────────► common       B3 C4 C#4 D4   common ───────────► rare
```

- **Each hand keeps its laptop letters** (QWERTY split). The most used letters sit on white
  keys right next to the centre; rare ones go outward and onto black keys.
- **Space is middle C.** Backspace is just left of it, ×2 (double the last letter) and
  ✓ Complete just right.
- **One key** types that letter. **A word's letters pressed together** type the whole word
  (repeated letters once: "letter" = L E T R).
- **A chord's word waits underlined** until you accept it. ✓ Complete accepts it, S1–S3 pick
  another of the words those letters make, ⌫ rejects it, and playing on accepts it as shown.
  The local AI picks which word fits your sentence while it waits.
- **While you spell a word**, the likely rest of it shows greyed out ("I li~~ke~~"). ✓ Complete
  types it; nothing is typed until you press it.
- **↶ Undo** takes back the last action. **⇧ Shift** capitalises the next letter.

The layout is generated by `layout_laptop.py` (written to `layout.json`). Inside the rules above
it still prefers word chords that sound good and letters the laptop can hear apart. The older
"musical" layout (common words make nice chords, like **the** = A major) is in
`layout_musical_backup.json`; copy it over `layout.json` to use it.

- **Type into other apps**: flip the toggle in the top bar, then click into Notes /
  Discord / Word within 3 seconds. While it's on, the page ignores your laptop keys so the
  app can't type into itself in a loop.
- **Simulate**: no piano? Click the on-screen keys, or use your laptop keyboard.
  Hold several letter keys down together and release to play a chord. Tab = ✓, Ctrl+Z = undo.

## Tuning tips

- Missed notes → raise **sensitivity**. Ghost/extra notes → lower it, or turn the
  keyboard volume down a little.
- Chords split into separate letters → raise **chord window** (e.g. 100 ms).
  Fast letters merging into chords → lower it.
- The AI runs locally through Ollama. Smaller models are faster: if suggestions
  feel slow, run `ollama pull qwen2.5:1.5b` and pick it in settings.

## Files

| file | what |
|---|---|
| `server.py` | the app (web server + typing logic) |
| `audio_engine.py` | listens to the keyboard, detects notes and chords |
| `words.py` | word list, chord → word lookup, next-letter odds |
| `ai.py` | local AI (Ollama) for word choice and suggestions |
| `layout_laptop.py` | finds the folded-laptop layout → `layout.json` |
| `layout.py` | the older musical layout (and shared helpers) |
| `bytedance_detector.py` | optional ByteDance piano-transcription detector (experimental, separate venv) |
| `typer.py` | types into other Windows apps |
| `web/` | the interface |
| `test_*.py` | tests (`python test_audio_engine.py`, `python test_server_logic.py`) |

## How well it works (tested on synthetic piano audio — not yet on the real keyboard)

| | without calibration | after "Calibrate all keys" |
|---|---|---|
| single letters | ~97% | ~98–100% |
| 2–4 note word chords | ~84% | ~96% |
| 5–6 note word chords | ~46% | ~94% |

Typing a whole test phrase from synthesised audio after calibration came out exactly
right, apart from one anagram ("how"/"who") that the AI fixes from context.
Real-world accuracy depends on your keyboard, volume and room, so do the calibration.
